# Portfólio — Ákila Ariel Pontes Armeres
Next.js 14 + React 18. APIs: Open-Meteo (clima) e GitHub REST (repositórios).

## Rodar
npm install && npm run dev  → http://localhost:3000

## Personalizar
Edite `data/perfil.js` (usuário do GitHub, e-mail, LinkedIn, instituições e datas).

## Publicar
1. `git init && git add . && git commit -m "portfolio" && git push` para um repositório no GitHub
2. vercel.com → Add New Project → importe o repositório → Deploy
